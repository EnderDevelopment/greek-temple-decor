# Greek Temple Decorations — Bedrock Addon

A Minecraft Bedrock Edition addon featuring Ancient Greek temple decorations: one monumental seated statue of Zeus and six decorative marble blocks in authentic classical Greek relief style. This mod adds custom 3D geometry, carved marble textures, and seamless decorative frieze blocks perfect for building temples, palaces, or classical structures.

## Install

1. Download the `GreekTemple.mcaddon` file from the release section.
2. Double-click the file to import it into Minecraft Bedrock Edition.
3. Create a new world or open an existing one.
4. Go to **Settings → Behavior Packs** and activate "Greek Temple Decorations".
5. Go to **Settings → Resource Packs** and activate "Greek Temple Decorations Resources".
6. In the same world settings, enable **Experiments → Holiday Creator Features**.
7. Start the world and find the new blocks in the creative inventory.

## Use

1. Open the creative inventory and navigate to **Construction → Decorated Stone** (look for the "Decorated Stone" group).
2. Place the **Zeus Statue** block on the ground — it will appear as a majestic seated statue with throne, robes, beard, hair, and lightning bolt, standing about 5-6 blocks tall.
3. Use the six decorative marble blocks to build continuous patterns and friezes:
   - `greektemple:meander_block` — Greek key border
   - `greektemple:warrior_block` — warrior with shield and spear
   - `greektemple:procession_block` — ceremonial procession
   - `greektemple:chariot_block` — horses and chariot
   - `greektemple:acanthus_block` — acanthus leaf ornament
   - `greektemple:floral_block` — floral and vine pattern
4. Place decorative blocks side by side to create seamless horizontal friezes around your temple.
5. For commands, use: `/give @s greektemple:zeus_statue`, `/give @s greektemple:meander_block`, etc.
